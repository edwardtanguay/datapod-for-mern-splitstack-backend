# datapod-for-splitstack-lern-backend

This is the backend of a splitstack React/Node/Express/lowdb-json application.

## features

- Node/Express
- TypeScript
- lowdb with db.json - _datasource_

## setup

- `npm i`
- `npm run dev`

## ports

- API runs on port: 3335, change this in config.ts
